Administration
This device is not admitted.

For security, only devices approved at the NAS console can sign in. At the serial console, type:

nas admit <ip>

Accounts with the admin role only. Create one at the console: user add <name> <password> admin

Encrypted connection (TLS 1.3) with the NAS's self-signed certificate. The first time, check that the SHA-256 fingerprint shown by the browser matches the one printed by the tls command at the console.
